# 00 · 项目总览与规则

## 1. 目标与成功标准

**总目标**：在两块 RTX 4090 上，从零训练一个自己的 LLM（198M 总参数 / 64M 激活的 MoE），具备：

1. 中文为主的通用语言能力与基础世界知识；
2. 可开关的思维链（thinking）能力，复杂任务显著受益、简单任务不过度思考；
3. 基本的工具调用能力（6 种内置工具）；
4. 最终能以 GGUF 量化格式在 Ollama 上流畅运行；
5. 架构对多模态（先视觉，后音频/TTS）可平滑扩展。

**成功标准（软指标，详见评测文档）**

- 思考开关有效：数学/推理类任务上，开启思考相比关闭思考的准确率有稳定正增益；
- 不过度思考：闲聊类问题不以长篇思考回复；
- 工具任务：在 agent 测试集上，工具调用格式合法率 > 95%，答案命中率（gt 匹配）显著高于 SFT 基线；
- 长文本：32k Needle-in-a-Haystack 基本可用；
- MoE 健康：各专家负载无坍塌（每个专家 token 占比不长期偏离均衡点 ±20% 以上）。

## 2. 硬约束

- 训练机：单机 2× RTX 4090（24GB/卡，无 NVLink，PCIe 互联）→ 用 **DDP（数据并行）** 即可，无需 TP/FSDP。
- 数据在服务器 `/media/liuzh/data/DLData/LocalSight`，当前账号**只读**，不修改、不移动原始数据；派生数据放项目目录下。
- 原始数据不在 git 中；训练产物（checkpoint/日志/GGUF）不在 git 中。
- 本地（macOS）负责编码与 git，服务器负责训练；本地不装训练依赖。

## 3. 核心原则

1. **实测驱动**：任何「假设」先查真实数据/跑小实验，再写进规则。本次已实测全部 6 个数据文件与 tokenizer（见 02 文档）。
2. **一遍过 + 闸门**：五个阶段各跑一次主训练（pretrain→sft→dpo→rlaif→agent_rl，顺序不可调换）；每阶段结束有评测闸门，不达标先诊断、只允许一次定向重训，不允许静默跳过。「一遍过」指阶段流程单次推进，不指数据必须单 epoch——pretrain 的 epoch 数由语料规模决定。
3. **生态兼容**：权重命名对齐 Qwen3-MoE，能低成本转 transformers / llama.cpp / Ollama / vLLM。
4. **自研核心、复用外围**：RMSNorm、RoPE、KV Cache、MoE、Muon、采样与损失函数自己写（学习与可控性）；tokenizer、数据集加载、配置解析、日志、SFT 训练循环可调包（HF 生态）。
5. **多模态预留，不提前实现**：现在只设计「编码器/投影器」接口与 token 协议，不写视觉塔代码，避免过早复杂化。
6. **可复现**：seed、数据 hash、环境锁、配置全部入库。

## 5. 关键决策记录（ADR）

| # | 决策 | 依据 |
| --- | --- | --- |
| D1 | 采用 MiniMind-3-MoE 骨架：768/8 层/8Q/4KV，4 专家 top-1，无共享专家 | 生态成熟、Qwen3-MoE 命名兼容、4090 可训 |
| D2 | 专家 FFN 维度 = **2432**（不是 2048） | 实测参数账：2432 → 198M/64M；2048 只有约 170M |
| D3 | 词表沿用提供的 6400 BPE | 词表已含思考/工具/多模态特殊 token；重训词表会推翻数据准备，收益不确定 |
| D4 | 路由用 aux-loss-free 偏置法 + z-loss（升级 MiniMind 原版的 aux loss） | 小模型 top-1 易坍塌，DeepSeek-V3 偏置法不干扰梯度 |
| D5 | 注意力在 4090 上用 FlashAttention-2/SDPA，不声称支持 FA3 | FA3 内核仅 Hopper（sm90）；4090 是 Ada（sm_89） |
| D6 | pretrain 主语料用全量 7.8GB（约 4.15B tokens），mini 用作开发/冒烟 | 全量≈198M 模型 Chinchilla 最优量；mini 只有 0.61B |
| D7 | DPO 数据定位为「通用质量偏好」，不含思考格式；思考质量偏好交给 RLAIF | 实测 17,166 对全部无 `<think>` |
| D8 | RLAIF 数据定位为「末轮留空的补全 prompt」 | 实测 19,502 条末轮 assistant 均为空串 |
| D9 | Agent RL 用 2 万条带工具+gt 的任务，内置 6 种工具执行器 | 实测无交互环境；gt 可做结果奖励 |
| D10 | 训练并行用 DDP | 198M 模型整卡复制显存充裕，无需复杂并行 |

## 6. 风险清单

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 语料是合成/指令型文本，非真实世界语料，知识与多样性可能不足 | 模型上限 | 接受为已知边界；去重 + 质量过滤；评测以相对目标为准 |
| 6400 词表中文压缩率一般（~1.47 字符/token），序列偏长 | 吞吐/长文 | 预算已按实测 tokens 估算；必要时再评估扩词表 |
| top-1 路由坍塌 | 无法训练 | 偏置式负载均衡 + z-loss + 每步负载监控 + 兜底 aux loss |
| Muon 与 MoE/编译交互出问题 | 进度 | Stage 0 冒烟测试覆盖；备胎 AdamW 全程 |
| RLAIF 的 judge 耗时过长 | 墙钟时间 | judge 可换 7B/8B 本地 vLLM 或轻量 RM；可缩小 K 与轮数 |
| 服务器磁盘/资源被其他项目占用 | 进度 | 只写 ~/project/LocalSight；运行前检查显存与磁盘 |
| 远程 git 凭据/网络 | 协作 | 本地与服务器都走 git；失败时手工 rsync 兜底 |
